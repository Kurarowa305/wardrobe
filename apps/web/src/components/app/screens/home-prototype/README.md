# #277 ホームUI試作（破棄可能）

既存 `/home` 上で、天気欄とダイアログの配置を3案比較する。合意済みのテンプレート一覧カード、5モード、スクロール末尾の「+ その他から記録」は共通。

```sh
pnpm prototype:home
```

- A: http://localhost:3277/home?variant=A — コンパクトな天気欄、中央のダイアログ。
- B: http://localhost:3277/home?variant=B — 最高・最低を左右に分け、ダイアログは画面下から表示。
- C: http://localhost:3277/home?variant=C — 予報を大きく表示し、ダイアログは画面幅を広く使う。

下部の黒い比較バーで案を変更する。入力等にフォーカスがない時は左右キーでも切替可能。「検証」で状態・処理結果を指定する。地域検索例は「府中」「新宿」「大阪」「札幌」「那覇」。構成服画像は試作用の図形であり、カードの配置は既存一覧を踏襲する。

地域・天気・推薦・保存はすべてメモリ内の架空データ。QWeatherへの実接続や実データの変更はない。他タブ、テンプレート追加、「+ その他から記録」の遷移先は説明のみ表示する。表示はdevelopment限定で、通常のホームはvariantパラメータを付けない場合に維持する。

## レビューすること

- 320px幅で5モードが収まり、縦3件のカードを比較できるか。
- 長いテンプレート名と20服のカード（4枚＋16）を確認できるか。
- 日付入力はJSTの今日で始まり、過去日・未来日も入力可能。
- 背景タップで閉じない。キャンセル／Escapeで戻り、フォーカスが復帰する。
- 記録中は操作不可。失敗確定時は日付を保持。成功通知と推薦再取得失敗を分ける。
- 地域未設定でも手動推薦を使える。検索中・候補なし・検索失敗・保存失敗を比較できる。
- 天気取得中／失敗／当日キャッシュ、推薦取得中／失敗、候補0〜3件を比較できる。

## 未確定・試作の限界

人間レビュー前の候補であり、採用済みではない。実際のQWeather検索品質、地域情報の保存条件、API契約は後続判断。保存結果不明時の再送、日付跨ぎ、確認中のテンプレート変更は#276/#283で整理する。本試作は成功後の順位変更を循環表示で模擬するのみで、実際の推薦計算ではない。天気数値・当日キャッシュも表示確認用。

本番実装は#282/#283で行う。試作コードは本番ブランチにそのまま取り込まない。
