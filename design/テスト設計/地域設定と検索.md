# 地域設定と検索 #279

公開境界は地域API handler、Web endpointとMSW。APIのGET/PUT永続化テストは同一repo adapterを共有する別呼出で観測し、検索は同梱辞書を使用する。DB依存はadapterで制御する。CAS競合は同じrevisionの同時保存のうち一方のみ成功することを検証する。

- `pnpm --filter api test:region`: 既存未設定0/null、保存・別取得・解除、revision増加、名前・作成日時維持、再送409、同時保存、未知wardrobe、未知コード、辞書版違い、不正入力、未知属性、整数型、JSON Content-Type、検索のかな/NFKC・同名・1文字・政令市区・10件打切り・空結果、Lambdaルーティング・重複query拒否。
- `pnpm --filter api test:region-web`: 実際のfetch wrapper/PUT、応答DTO検証、入力正規化、MSWの作成済wardrobe取得・地域保存・解除・競合・404。
- `python3 scripts/generate-region-dictionary.py --check`: 承認済CSV 3点のSHA、1,918件結合、座標、生成物完全一致。
- 既存API/Webテスト、型検査、Lambdaパッケージ、frozen-lockfileを回帰確認する。

CIに上記3つを追加。TDD証拠: region GET handler未実装でTypeError、Web MSW未実装でERR_MODULE_NOT_FOUNDを確認してから各縦断実装で成功。
