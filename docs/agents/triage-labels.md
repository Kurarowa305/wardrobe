# Triage Labels

スキルの canonical role と、このリポジトリで使用するラベルの対応です。

| Role | ラベル | 意味 |
| --- | --- | --- |
| needs-triage | needs-triage | メンテナーによる評価待ち |
| needs-info | needs-info | 報告者からの追加情報待ち |
| ready-for-agent | ready-for-agent | 仕様が揃い、エージェントが実装できる |
| ready-for-human | ready-for-human | 人による実装が必要 |
| wontfix | wontfix | 対応しない |

スキルが role を指定したら、この表の対応ラベルを使用してください。
名称を変更する場合はラベル列を編集してください。
