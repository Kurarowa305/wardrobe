# テンプレート推薦は全候補を読み直して計算する

[判断 Issue #275](https://github.com/Kurarowa305/wardrobe/issues/275) の対話で、推薦時にワードローブのテンプレート全ページと必要な構成服を読み直し、構成服の最終着用日の最大値で順位を計算する方針に合意した。推薦専用の集計データを持つ案は読み取り量を削減できる一方、服を共有する複数テンプレートへの更新反映と整合性管理が必要になるため、当初は採用しない。

取得経路はテンプレートのベーステーブルPKの全ページ強整合Queryと、必要な構成服の強整合BatchGetとする。新しいGSIは追加しない。登録数に応じた読み取り量の増加を許容し、後続実装で測定する。不完全な候補から選んだ上位3件を正常な推薦として返さない。取得開始前に完了した更新を反映するが、取得途中の並行更新に対する全体の同一時点スナップショットは保証せず、次回取得で反映する。

本ADRは取得方式と保証範囲の判断を記録するものであり、実装完了を意味しない。推薦取得の自動再試行は行わない。取得制約・キャッシュ無効化の合意と後続への引き継ぎは[判断資料](../../design/タスク設計/天気連動テンプレート推薦_取得整合性判断.md)を参照する。
